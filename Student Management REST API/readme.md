# Student Management REST API

## About

This project is a Student Management REST API built using Node.js and Express.js.

The API allows users to perform CRUD operations on student records using REST APIs.

Student data is stored using an array/JSON data structure. No database is used.

## Technologies Used

- Node.js
- Express.js
- Postman
